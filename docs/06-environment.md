## Воспроизведение инструментальных проверок

**Lighthouse**

1. Открыть `/overall`.
2. DevTools → Lighthouse → Mode: Navigation, Device: Desktop, категории Accessibility / SEO / Best Practices.
3. Analyze page load.

**Заголовки безопасности**

1. DevTools → Network → обновить страницу.
2. Выбрать документ → Headers → Response Headers.
3. Проверить наличие CSP, HSTS, X-Frame-Options, Referrer-Policy, X-Content-Type-Options.

**CORS**

1. Открыть вкладку Network с фильтром Fetch/XHR.
2. Выполнить действие, дергающее API (например, сохранение профиля).
3. В Response Headers проверить `Access-Control-Allow-Origin` и `Access-Control-Allow-Credentials`.

## Ограничения окружения

- Расширения браузера отключены, чтобы не влиять на замеры.
- Результаты Lighthouse зависят от версии браузера и сети; сохранён HTML-отчёт как снимок состояния.
- Скриншоты делались в разные моменты; часть дефектов подтверждена текстом и Network, а не изображением.
